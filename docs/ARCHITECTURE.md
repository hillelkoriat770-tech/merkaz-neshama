# ארכיטקטורה

- **ממשק:** Next.js App Router, React, TypeScript.
- **שפה:** עברית, `lang="he"`, `dir="rtl"`.
- **זהות:** Supabase Auth; Google הוא ספק OAuth שמוגדר בלוח הבקרה.
- **נתונים:** PostgreSQL/Supabase — סכמות ו-RLS יתווספו בשלב נפרד.
- **אינטגרציות:** תשלומים, וידאו, Zoom ודוא״ל צריכים שכבת Adapter/Service.

## מודולים מתוכננים
קורסים ושיעורים, התקדמות תלמיד, שיעורים חיים, אירועים, קהילה, שאל את הרב (פרטי כברירת מחדל), הזמנות ותשלומים, התראות, ניהול משתמשים ו-Audit Log.

## עדיין לא ממומש
מסד נתונים עסקי, RLS, הרשאות מנהל, סליקה, אחסון וידאו, Zoom והתראות. יש לבנות ולבדוק לפני השקה.
