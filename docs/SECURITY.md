# אבטחה ופרטיות

- אין לשמור מפתחות סודיים ב-Git או בקוד לקוח.
- כל משתנה `NEXT_PUBLIC_*` חשוף לדפדפן.
- אין להשתמש במפתח Supabase `service_role` בצד לקוח.
- יש להפעיל RLS לכל טבלה פרטית ולבדוק הרשאות גם בשרת.
- שאלות אישיות לרב פרטיות כברירת מחדל.
- יש להוסיף rate limiting, audit logs, ניטור, גיבויים ותוכנית שחזור.
- לפני Production יש לבצע סקירת אבטחה ולבדוק את דרישות הפרטיות והדין הרלוונטיות.
